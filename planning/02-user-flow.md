# 모둠톡 사용자 흐름

## 이 문서의 역할

이 문서는 교사와 모둠 공용 기기가 어떤 계기와 상태를 거쳐 핵심 결과에 도달하는지 정의한다. 제품의 사용자·범위·제품 규칙은 [01-product-spec.md](01-product-spec.md)가 기준이다.

이 문서는 비실행형 기획 문서다. 내부 처리 순서와 구체적인 화면 구현은 17:30 이후 결정한다.

## 역할별 목표

| 역할 | 시작할 때 알고 싶은 것 | 활동 중 알고 싶은 것 | 끝날 때 알고 싶은 것 |
|---|---|---|---|
| 교사 | 어떤 활동과 모둠을 시작하는가? 어느 모둠이 준비됐는가? | 어느 모둠을 먼저 살펴봐야 하는가? 정보는 믿을 만한가? | 실시간 수집이 끝났는가? 무엇이 남는가? |
| 모둠 공용 기기 | 올바른 활동과 모둠을 선택했는가? | 대화가 수집 중인가? 문제가 생기면 무엇을 해야 하는가? | 수집이 실제로 끝났는가? |
| 학생과 모둠 | 왜 대화 정보가 사용되는가? 누가 보는가? | 참여 정보가 어떻게 사용되는가? | 더 이상 대화가 수집되지 않는가? |

## 전체 제품 지도

```text
활동 준비
  → 모둠 입장·확인
  → 준비 상태 확인
  → 활동 시작
  → 대화 수집과 참여 상태 확인
  → 교사의 모둠 확인·수업 개입
  → 활동 종료
  → 확장: 대화 단계·주제 관련성·요약·사후 보고
```

핵심 시연은 활동 준비부터 활동 종료까지다. 마지막 확장 구간은 전체 제품 맥락만 보여 주며 필수 시연 범위가 아니다.

## 핵심 시연 6단계

### 1. 활동 준비

**교사의 계기**

모둠 토의를 시작하기 전에 활동 주제와 모둠 구성을 확인한다.

**교사에게 보여야 하는 것**

- 활동 이름과 주제
- 참여할 모둠
- 모둠 공용 기기의 준비 상태
- 모둠이 들어올 수 있는 안내

**다음 단계 조건**

교사는 어떤 모둠이 준비됐고 아직 준비되지 않았는지 이해한다. 준비되지 않은 모둠이 있어도 시작 여부는 교사가 판단한다.

### 2. 모둠 확인

**모둠 공용 기기의 계기**

교사가 공유한 안내로 활동에 들어온다.

**모둠에게 보여야 하는 것**

- 들어온 활동과 토의 주제
- 선택한 모둠 이름
- 잘못 선택했을 때 다시 선택하는 행동
- 확인 후 교사가 시작할 때까지 기다린다는 안내

**교사에게 보여야 하는 것**

- 준비된 모둠과 준비 전 모둠
- 한 모둠의 중복 기기가 참여 인원으로 오해되지 않는 상태

**다음 단계 조건**

모둠은 올바른 활동과 모둠을 확인했고, 교사는 그 모둠의 공용 기기가 준비됐음을 안다.

### 3. 활동 시작

**교사의 행동**

준비 상태를 확인하고 활동을 시작한다.

**양쪽에 보여야 하는 것**

- 교사: 활동이 진행 중이라는 상태
- 모둠 공용 기기: 대기에서 수집 준비 또는 수집 중으로 바뀐 상태
- 학생과 모둠: 대화 정보의 사용 목적과 교사가 본다는 안내

**다음 단계 조건**

교사와 모둠이 활동 시작 여부를 다르게 이해하지 않는다.

### 4. 대화 수집

**모둠의 행동**

공용 기기에서 대화 수집을 시작하고 토의한다.

**모둠에게 보여야 하는 것**

- 수집 중인지 여부
- 연결과 마이크 상태
- 연결을 끝내는 행동
- 문제가 생겼을 때 다시 연결하는 행동

**교사에게 보여야 하는 것**

- 모둠별 정보가 들어오고 있는지
- 아직 정보가 부족한지
- 최근 상태인지, 갱신이 멈췄는지

**다음 단계 조건**

교사는 참여 문제와 데이터·연결 문제를 구분할 수 있다.

### 5. 먼저 살펴볼 모둠 찾기

**교사의 계기**

여러 모둠이 동시에 토의하고 있어 모든 모둠을 직접 계속 관찰할 수 없다.

**교사에게 보여야 하는 것**

| 합성 모둠 | 상태 | 교사가 이해할 의미 | 다음 행동 |
|---|---|---|---|
| 햇살 | 여러 익명 화자가 고르게 참여하는 경향 | 현재는 즉시 확인할 우선순위가 낮다. | 활동을 계속 관찰한다. |
| 나무 | 한 익명 화자 중심 경향 | 추가 확인이 필요한 후보다. | 먼저 모둠을 살펴본다. |
| 바다 | 정보 부족 | 참여 상태를 아직 판단할 수 없다. | 조금 더 기다리거나 수집 상태를 확인한다. |
| 구름 | 연결 실패 | 참여 문제가 아니라 기술 상태를 먼저 확인해야 한다. | 공용 기기의 연결 회복을 돕는다. |

**제품 한계 표시**

- 참여 경향은 학생 평가 점수가 아니다.
- 익명 화자 표시는 학생 이름과 같지 않다.
- 정보가 부족하거나 오래됐으면 참여 경향을 단정하지 않는다.

**다음 단계 조건**

교사는 나무 모둠을 먼저 살펴볼 이유와, 구름 모둠에는 연결 확인이 먼저인 이유를 설명할 수 있다.

### 6. 활동 종료

**교사의 행동**

활동 종료를 선택한다.

**양쪽에 보여야 하는 것**

- 교사: 실시간 정보가 더 들어오지 않는 종료 상태
- 모둠 공용 기기: 대화 수집이 끝났다는 상태
- 학생과 모둠: 어떤 정보가 남을 수 있고 무엇이 미결정인지에 대한 안내

**완료 조건**

교사와 모둠 모두 활동과 대화 수집이 끝났음을 안다. 종료 이후의 실시간 변화는 진행 중 상태처럼 보이지 않는다.

## 실패와 복구 흐름

### 잘못된 모둠 선택

1. 모둠 공용 기기가 선택한 활동과 모둠을 확인한다.
2. 잘못된 경우 시작 전에 다시 선택한다.
3. 교사는 바뀐 준비 상태를 확인한다.

사용자는 내부 오류를 이해할 필요 없이 현재 선택과 바로잡는 행동을 알아야 한다.

### 늦은 입장

1. 활동이 이미 시작된 뒤 모둠 공용 기기가 들어온다.
2. 기기는 현재 활동이 진행 중임을 알린다.
3. 모둠 확인과 수집 시작을 거친다.
4. 교사는 새로 준비된 모둠과 아직 정보가 부족한 상태를 구분한다.

늦은 입장을 참여 부족으로 해석하지 않는다.

### 정보 부족

1. 대화 수집이 시작됐지만 아직 참여 경향을 말할 근거가 부족하다.
2. 교사 화면은 ‘판단할 정보가 부족함’을 표시한다.
3. 충분한 정보가 생기기 전에는 정상·편중을 단정하지 않는다.

### 연결 실패

1. 모둠 공용 기기가 대화 상태를 전달하지 못한다.
2. 모둠 기기는 마이크·연결 확인과 다시 연결 행동을 보여 준다.
3. 교사는 참여 경향 대신 연결 확인 필요를 본다.
4. 연결이 회복되면 수집 상태로 돌아가고, 교사는 정보 최신성을 확인한다.

### 판단 불가

정보는 있지만 신뢰할 수 없거나 해석이 확실하지 않은 경우 교사는 ‘판단 불가’와 이유를 본다. 이 상태를 정상이나 문제로 바꾸어 표시하지 않는다.

### 종료 중 연결 문제

활동 종료가 선택되면 모둠 기기의 연결 문제와 관계없이 교사 화면은 종료 의도를 분명히 보인다. 모둠 기기가 다시 연결되더라도 종료된 활동을 진행 중으로 오해하지 않게 한다.

## 상태 의미 기준

| 사용자용 상태 | 의미 | 사용자가 할 일 | 의미하지 않는 것 |
|---|---|---|---|
| 준비 전 | 모둠 공용 기기가 아직 확인되지 않음 | 입장과 모둠 확인을 기다린다. | 학생이 결석했다는 뜻이 아님 |
| 준비됨 | 공용 기기가 활동과 모둠을 확인함 | 교사 시작을 기다린다. | 대화 수집이 이미 시작됐다는 뜻이 아님 |
| 수집 중 | 공용 기기가 대화 상태를 전달 중 | 토의를 진행하고 상태를 확인한다. | 원본 음성이 장기 저장된다는 뜻이 아님 |
| 정보 부족 | 참여 경향을 말할 근거가 아직 부족함 | 기다리거나 수집 상태를 확인한다. | 참여가 나쁘다는 뜻이 아님 |
| 편중 경향 | 한 익명 화자 중심 경향이 관찰됨 | 교사가 직접 모둠을 확인한다. | 학생 평가나 확정 진단이 아님 |
| 판단 불가 | 현재 정보로 신뢰할 판단을 할 수 없음 | 이유와 최신성을 확인한다. | 정상 상태가 아님 |
| 연결 실패 | 모둠 상태 전달이 중단됨 | 공용 기기의 연결을 확인한다. | 모둠 참여 문제가 아님 |
| 종료 | 활동과 실시간 수집이 끝남 | 다음 활동 또는 사후 확인으로 이동한다. | 수집이 계속된다는 뜻이 아님 |

## 화면 지도

| 역할 | 핵심 화면 상태 | 필수 정보 | 핵심 행동 |
|---|---|---|---|
| 교사 | 활동 준비 | 활동·주제·모둠·준비 상태 | 입장 안내 확인, 활동 시작 |
| 교사 | 실시간 상태 | 모둠별 참여 경향·정보 최신성·오류 | 먼저 살펴볼 모둠 선택, 활동 종료 |
| 교사 | 종료 | 수집 종료와 남는 정보 안내 | 종료 확인, 확장 보고로 이동 가능 |
| 모둠 공용 기기 | 모둠 확인 | 활동·주제·선택 모둠 | 다시 선택, 확인 |
| 모둠 공용 기기 | 대기 | 교사 시작 전 상태 | 기다림 |
| 모둠 공용 기기 | 수집 중 | 수집 목적·현재 상태 | 연결 종료 |
| 모둠 공용 기기 | 연결 실패 | 문제와 복구 안내 | 다시 연결 |
| 모둠 공용 기기 | 종료 | 수집 종료 | 종료 확인 |

## 확장 흐름

핵심 시연 이후 다음 흐름을 전체 제품 지도에만 표시한다.

- 교사가 모둠의 대화 단계·주제 관련성·근거를 추가로 확인한다.
- 교사가 활동 종료 후 요약·키워드·모둠별 보고를 확인한다.
- 교사가 같은 모둠 편성이나 활동 구조를 다음 수업에 재사용한다.

확장 흐름은 핵심 시연이 실패했을 때 이를 대신하는 성공 조건이 아니다.

## 미결정과 이후 확인

- 실제 교사가 가장 먼저 보는 정보 순서와 한 화면에서 비교 가능한 모둠 수
- 실제 학생이 이해하기 쉬운 수집 안내 문구
- 대상 학교급에 따른 표현과 보호자·학교 안내
- 실제 수업 유형별로 참여 균형이 유효하거나 오해를 부르는 조건

이 항목은 실제 사용자 검증 전에 확인하며, 현재 핵심 시연에서는 합성 사례로 명확한 상태 구분을 먼저 검증한다.
