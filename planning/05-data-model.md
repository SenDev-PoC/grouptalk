# 모둠톡 개념 데이터 모델

## 이 문서의 역할

이 문서는 모둠톡이 다루는 핵심 정보 개념과 관계, 소유권, 민감도, 생성·변경·종료의 의미를 설명한다. 저장 형식과 기술 구조를 정하는 문서가 아니다.

구체적인 저장·전송 방식은 17:30 이후 새 저장소에서 결정한다.

## 모델링 원칙

- 사용자와 제품이 이해해야 하는 개념만 다룬다.
- 원본 정보와 파생 정보를 구분한다.
- 익명 화자 표시와 학생 이름을 같은 개념으로 두지 않는다.
- 활동 종료와 정보 삭제를 자동으로 같은 사건이라고 가정하지 않는다.
- 보존 기간과 책임자가 미정이면 미정이라고 표시한다.
- 해커톤 합성 데이터와 실제 학생 정보를 구분한다.

## 개념 지도

```text
활동
 ├─ 여러 모둠을 포함한다.
 ├─ 하나의 활동 상태를 가진다.
 └─ 활동 주제와 정보 사용 목적을 가진다.

모둠
 ├─ 한 활동에 속한다.
 ├─ 하나의 공용 기기 상태를 가진다.
 ├─ 여러 대화 관찰을 가진다.
 └─ 시간에 따라 참여 상태가 달라질 수 있다.

모둠 공용 기기 상태
 ├─ 활동·모둠 확인과 준비 상태를 나타낸다.
 └─ 대기·수집·연결 실패·종료 상태를 나타낸다.

대화 관찰
 ├─ 한 활동과 모둠 맥락에 속한다.
 ├─ 익명 화자 표시를 포함할 수 있다.
 └─ 참여 상태와 확장 분석의 근거가 될 수 있다.

참여 상태
 ├─ 참여 경향을 나타낸다.
 ├─ 정보 충분성·최신성·판단 가능성을 포함한다.
 └─ 학생 평가가 아니다.

확장 분석
 └─ 대화 단계·주제 관련성·근거·요약·키워드를 포함할 수 있다.
```

## 핵심 개념

### 활동

**의미**

교사가 준비·시작·종료하며 모둠 대화가 진행되는 수업 단위다.

**주요 속성의 의미**

- 사용자가 알아보는 활동 이름과 토의 주제
- 준비 전, 진행 중, 종료의 활동 상태
- 참여할 모둠
- 대화 정보를 사용하는 목적

**소유와 변경**

- 교사가 준비하고 시작·종료한다.
- 모둠 공용 기기는 상태를 확인하지만 활동 자체를 변경하지 않는다.

**수명**

활동 종료 후에도 제품 설명이나 사후 보고에 필요한 일부 정보가 남을 수 있다. 남는 정보의 종류와 기간은 실제 학생 검증 전에 결정한다.

### 모둠

**의미**

같은 활동에서 함께 대화하고 교사가 비교·관찰하는 학생 집단이다.

**주요 속성의 의미**

- 사용자가 알아보는 모둠 이름
- 활동과의 관계
- 공용 기기 준비·연결 상태
- 현재 참여 상태와 정보 최신성

**주의**

모둠 공용 기기의 준비 상태는 개인 학생의 출석 상태가 아니다.

### 모둠 공용 기기 상태

**의미**

모둠이 함께 사용하는 기기가 올바른 활동·모둠을 확인했고 대화 수집이 가능한지 나타낸다.

**상태 범위**

- 준비 전
- 준비됨
- 확인 필요
- 대기
- 수집 중
- 정보 부족
- 연결 실패
- 종료

**수명**

한 활동 안에서만 의미가 있다. 다른 활동의 준비·연결 상태로 자동 이어지지 않는다.

### 대화 관찰

**의미**

활동 중 모둠의 대화를 제품 목적에 맞게 이해하기 위해 관찰한 정보다.

**구분해야 할 정보**

- 원본 음성
- 전사된 대화 내용
- 익명 화자 표시
- 관찰 시점과 최신성

**주의**

- 원본 음성은 장기 보존을 핵심 가치로 삼지 않는다.
- 전사문에는 이름이 없어도 민감한 발언이 포함될 수 있다.
- 대화 관찰은 학생 개인의 확정 신원이 아니다.

### 익명 화자 표시

**의미**

같은 대화 안에서 서로 다른 발화 경향을 구분하기 위한 임시 표지다.

**제품 규칙**

- 학생 이름과 자동으로 연결하지 않는다.
- 같은 표지가 항상 같은 학생이라는 보증을 제품 가치로 삼지 않는다.
- 오류 가능성과 해석 한계를 교사에게 숨기지 않는다.

### 참여 상태

**의미**

교사가 먼저 살펴볼 모둠을 찾도록 돕는 모둠 수준의 보조 신호다.

**구성 개념**

- 참여 경향: 고른 경향 또는 한 화자 중심 경향
- 정보 충분성: 판단할 정보가 충분한가
- 판단 가능성: 현재 정보를 신뢰할 수 있는가
- 최신성: 최근 상태인가, 갱신이 멈췄는가
- 근거 설명: 교사가 왜 이 상태를 보는지 이해할 실마리

**제품 규칙**

- 학생 평가·성적·태도 점수가 아니다.
- 정보가 부족하면 경향을 단정하지 않는다.
- 연결 실패를 참여 문제로 바꾸지 않는다.

### 확장 분석

**의미**

핵심 참여 상태 이후 교사의 대화 이해를 추가로 돕는 정보다.

**포함 가능한 개념**

- 대화 단계
- 활동 주제와의 관련성
- 관련성 판단 근거
- 대화 요약
- 주요 키워드
- 활동 종료 후 모둠별 보고

**경계**

확장 분석은 핵심 시연의 필수 완료 조건이 아니다. 자동 생성 결과의 오류와 정정·삭제·보존 방식은 실제 도입 전에 별도로 결정한다.

### 정보 수명 결정

**의미**

각 정보가 왜 생기고 누가 보며 언제까지 남고 누가 삭제를 책임지는지에 대한 제품 결정이다.

**필수 질문**

- 목적: 왜 필요한가?
- 출처: 사용자 입력인가, 관찰 정보인가, 파생 정보인가?
- 열람: 교사·학생·학교·외부 처리자 중 누가 보는가?
- 보존: 활동 중만 필요한가, 활동 후에도 필요한가?
- 삭제: 어떤 조건에서 누가 삭제하는가?
- 권리: 실제 학생이 열람·정정·삭제를 요청할 때 누가 대응하는가?

## 관계와 소유권

| 개념 | 관계 | 제품상 소유·결정 주체 | 함께 보아야 할 경계 |
|---|---|---|---|
| 활동 | 여러 모둠을 포함 | 교사 | 활동 종료와 정보 삭제는 다를 수 있음 |
| 모둠 | 한 활동에 속함 | 교사가 구성, 모둠이 사용 | 공용 기기와 학생 개인을 구분 |
| 공용 기기 상태 | 한 활동과 모둠 맥락에 속함 | 모둠이 확인, 교사가 관찰 | 준비 상태는 개인 출석이 아님 |
| 대화 관찰 | 활동·모둠 맥락에 속함 | 정보 목적은 제품·학교가 결정 | 원본·전사·화자 표시를 구분 |
| 익명 화자 표시 | 대화 관찰 안에서 사용 | 자동 처리 결과, 교사가 한계를 확인 | 학생 이름과 동일시하지 않음 |
| 참여 상태 | 모둠과 시점에 속함 | 제품이 보조 신호 제공, 교사가 판단 | 평가 점수가 아님 |
| 확장 분석 | 대화 관찰에서 파생될 수 있음 | 제품이 보조, 교사가 검토 | 핵심 시연과 분리 |
| 정보 수명 결정 | 각 정보 종류에 적용 | 실제 도입 전 학교·제품 책임자 결정 | 미결정을 숨기지 않음 |

## 정보 민감도와 열람 기대

| 정보 | 민감도 관점 | 해커톤 시연 기본 | 실제 학생 검증 전 결정 |
|---|---|---|---|
| 활동·주제 | 수업 맥락을 드러낼 수 있음 | 합성 내용 사용 | 공개 범위와 보존 기간 |
| 모둠 이름 | 집단을 알아볼 수 있음 | 합성 이름 사용 | 실제 학급과 연결되는 범위 |
| 원본 음성 | 목소리·대화 내용 포함 가능 | 합성 또는 동의한 성인 대화 | 처리 주체·일시 보존·삭제 확인 |
| 전사문 | 개인·가정·건강 등 민감한 발언 포함 가능 | 합성 내용 사용 | 열람 주체·보존·정정·삭제 |
| 익명 화자 표시 | 다른 정보와 결합하면 개인 추정 가능 | 합성 대화 안의 임시 표지 | 재식별 위험과 오류 안내 |
| 참여 상태 | 학생 평가로 오해될 수 있음 | 수업 지원 신호로만 표시 | 활동 후 보존·학생 열람 여부 |
| 확장 분석 | 대화 내용의 자동 해석 포함 | 핵심 시연에서 필수 아님 | 외부 처리·근거·정정·삭제 |

## 수명 지도

| 단계 | 생길 수 있는 정보 | 사용자에게 알려야 할 것 | 현재 결정 상태 |
|---|---|---|---|
| 활동 준비 | 활동·주제·모둠 | 무엇을 위한 활동인가 | 핵심 시연에 포함 |
| 모둠 확인 | 선택 모둠·공용 기기 준비 | 개인 출석과 다른 상태임 | 핵심 시연에 포함 |
| 대화 수집 | 원본 음성·전사문·익명 화자 표시 | 목적·보는 주체·수집 중 상태 | 세부 보존은 미결정 |
| 참여 상태 생성 | 참여 경향·충분성·최신성 | 학생 평가가 아니며 한계가 있음 | 핵심 시연에 포함 |
| 활동 종료 | 종료 상태와 남는 정보 | 수집 종료와 정보 삭제의 차이 | 실제 보존 기간은 미결정 |
| 확장 분석 | 요약·키워드·관련성·보고 | 자동 생성 한계와 열람 범위 | 확장 범위 |

## 개념 상태 변화

### 활동

준비 전 → 준비 중 → 진행 중 → 종료

### 모둠 공용 기기

미확인 → 모둠 확인 → 대기 → 수집 중 → 종료

중간에 확인 필요·연결 실패·재연결 상태가 나타날 수 있다.

### 참여 상태

정보 없음 → 정보 부족 → 경향 표시

언제든 최신성 저하 또는 판단 불가 상태로 바뀔 수 있으며, 연결 실패는 별도 상태로 유지한다.

## 미결정

- 실제 정보 저장 여부와 보존 기간
- 삭제와 권리 요청의 책임자
- 실제 학교·외부 처리 주체 사이 책임
- 참여 경향과 확장 분석의 정정 방식
- 대상 학교급에 따른 안내·동의·보호 절차

미결정은 숨은 기본값으로 두지 않고 실제 학생 검증 전에 결정한다.
